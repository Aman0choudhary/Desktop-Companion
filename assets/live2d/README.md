# Live2D Assets

Place a legitimate Cubism model here if you want to replace the bundled sample.

Supported layouts:

```text
assets/live2d/nezuko.model3.json
assets/live2d/nezuko/nezuko.model3.json
assets/live2d/nezuko/textures/
assets/live2d/nezuko/motions/
```

You can also point the app at any `*.model3.json` file from the Settings window.

Notes:

- The bundled `Haru` folder is only a technical validation sample.
- A true Nezuko model is not bundled in this repo.
- If you change the Live2D model path in Settings, restart the app to load it.
